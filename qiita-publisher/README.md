# Qiita Publisher

Qiita 記事の企画から投稿までを一貫して行う Agent Skills スイート。

## スキル一覧

| スキル | 説明 |
|--------|------|
| `qiita-compose` | 記事コンテンツの企画・構成・Markdown 生成 |
| `qiita-post` | ブラウザ操作で Qiita に記事を投稿 |

## エージェント

| エージェント | 説明 |
|-------------|------|
| `qiita-writer` | 企画→執筆→投稿のフルサイクルエージェント |

## 前提条件

- ブラウザ操作ツール（Playwright MCP 等）が利用可能であること
- Qiita にログイン済みのブラウザセッションがあること
