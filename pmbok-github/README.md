# PMBOK GitHub Manager

GitHub Projects + Actions で PMBOK 知識エリアに基づくプロジェクト管理を実現する Agent Skills スイート。

## 対象範囲

| PMBOK知識エリア | カバー範囲 |
|----------------|-----------|
| 統合・スコープ管理 | WBS構築、要件定義、自動クローズ/ステータス移行 |
| スケジュール管理 | ガントチャート、依存関係、クリティカルパス判定、遅延時自動シフト |
| コスト管理 | EV算出、予定/実績工数の入力・集計 |
| 品質管理 | バグトラッキング、CI/CDテスト→自動差し戻し |
| リソース管理 | 担当者アサイン、キャパシティ可視化、自動アサイン |
| リスク管理 | リスク登録簿、発生確率・影響度、アラート |
| ステークホルダー | 週報・日報の自動生成 |

## サブスキル

| スキル | 用途 |
|--------|------|
| `pmbok-github-init` | GitHub Project 初期セットアップ |
| `pmbok-github-schedule` | スケジュール管理・自動化 |
| `pmbok-github-cost` | コスト・EV管理 |
| `pmbok-github-quality` | 品質管理・CI/CD連携 |
| `pmbok-github-risk` | リスク管理 |
| `pmbok-github-report` | レポート自動生成 |

## 前提条件

- GitHub Organization または個人アカウント
- GitHub Projects V2 が有効
- GitHub Actions が有効
- リポジトリへの Admin 権限（初期セットアップ時）

## 対象外

- プロジェクト憲章の厳格な承認ワークフロー（電子印鑑等）
- ベースライン（計画スナップショット）の厳密な保持と比較
- 人件費単価と連動した金額計算・Sカーブ描画
- テスト網羅率の複雑なマトリクス表作成
- 全社的な要員稼働率の調整
- モンテカルロ法等の高度な定量・確率分析
- 外注先との契約書・請求・支払管理
